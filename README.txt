FOOD MOOD — prototype HTML/CSS/JavaScript

Pour tester :
1. Décompressez food_mood_site.zip dans un dossier.
2. Gardez index.html, style.css, script.js et logo.jpeg ensemble.
3. Ouvrez index.html avec Chrome ou Edge.

Important :
- Les restaurants, prix, notes et commentaires sont des exemples de démonstration, pas des informations vérifiées.
- Les photos sont chargées depuis Unsplash, donc une connexion Internet est nécessaire pour les afficher.
- Le prototype n'a pas encore de base de données ni de comptes utilisateurs. Les avis et points sont temporaires.
